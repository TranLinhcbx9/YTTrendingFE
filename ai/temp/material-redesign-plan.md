# Redesign sang Angular Material 3 — Plan

**Scope đã chốt:** theo đủ ngôn ngữ thiết kế M3 (palette generate từ seed,
type scale, shape scale, elevation, density, navigation pattern), **giữ**
accent teal `#2BD4C2` làm seed + dark-first + mật độ dày hợp dashboard.

Phiên bản: `@angular/material@20.2.14` (khớp Angular 20.3.29 đang cài).

## Batch 2 — `src/styles/material-theme.scss` *(file mới)*

**Mục đích:** nơi duy nhất gọi `mat.theme()` — sinh toàn bộ `--mat-sys-*`
(màu, typography, shape, elevation, state) + token density cho component.

> **Vì sao:** `theme-type` để mặc định `color-scheme` nên Material emit
> giá trị dạng `light-dark(sáng, tối)`. Nghĩa là **chuyển sáng/tối chỉ
> cần đổi thuộc tính CSS `color-scheme`** — không cần lặp lại bảng màu 3
> lần như `tokens.css` hiện tại. Đây là lý do kỹ thuật chính khiến bản
> redesign này *ngắn hơn* bản đang có, chứ không dài hơn.
>
> `density: -2` vì đây là dashboard đọc số liệu: mặc định M3 cho row cao
> 52px, `-2` kéo về 40px — vẫn trong spec M3 (density là 1 trục chính
> thức của M3), không phải hack.
>
> `mat.theme-overrides` chỉ dùng cho `corner-*`: M3 mặc định bo 12–16px
> cho card/dialog, hơi tròn so với mockup dashboard. Kéo về 8/12 vẫn nằm
> trong shape scale M3.

```scss
@use '@angular/material' as mat;
@use './theme-colors' as theme;

html {
  @include mat.theme((
    color: (
      primary: theme.$primary-palette,
      tertiary: theme.$tertiary-palette,
      // theme-type mặc định = color-scheme → emit light-dark(), xem Vì sao
    ),
    typography: (
      plain-family: (Inter, sans-serif),
      brand-family: ('Be Vietnam Pro', sans-serif),
      bold-weight: 700,
      medium-weight: 600,
      regular-weight: 400,
    ),
    density: -2,
  ));

  @include mat.theme-overrides((
    corner-large: 12px,
    corner-medium: 10px,
    corner-small: 8px,
  ));

  // Mặc định: theo hệ điều hành. Toggle trong app thắng (xem tokens.css).
  color-scheme: light dark;
}
```

## Batch 3 — `src/styles/tokens.css` *(ghi đè toàn bộ file)*

**Mục đích:** lớp alias — dịch tên ngữ nghĩa của app (`--color-bg`,
`--color-surface`…) sang M3 role token, cộng các "extended color" mà M3
không có sẵn (status, heat). Vẫn là **nguồn duy nhất** cho màu như
invariant trong `AGENT.md` yêu cầu, chỉ khác là giá trị nay đến từ M3.

> **Vì sao giữ lớp alias thay vì xoá luôn và dùng thẳng `--mat-sys-*`:**
> `--mat-sys-surface-container-low` không nói lên "đây là nền card của
> app này". Giữ tên ngữ nghĩa thì đổi quyết định sau (ví dụ card đổi
> sang `surface-container`) chỉ sửa 1 dòng, không phải sửa mọi template.
> Đây cũng đúng cách M3 khuyến nghị: sys role → app-specific alias.
>
> **Vì sao `--color-text-muted` map vào `outline` chứ không phải
> `on-surface-variant`** (tên nghe hợp lý hơn): đã resolve thật từ role→tone
> map của Material 20 — ở dark, `on-surface-variant` = `neutral-variant 90`
> = `#d6e6e2`, gần như trùng `on-surface` (`#dde4e1`), nên chữ "phụ" sẽ
> không hề phụ. `outline` cho `#6b7a77` sáng / `#859490` tối — mờ đúng mức
> trên cả hai nền. `text-faint` không còn role riêng nên pha loãng từ
> `outline`.
>
> **Vì sao status/heat không map vào M3 role:** M3 chỉ có
> primary/secondary/tertiary/error. Nhét 3 trạng thái vòng đời + 3 bậc
> nhiệt vào đó sẽ sai ngữ nghĩa (và `error` đã dành cho `--color-danger`).
> M3 gọi trường hợp này là *custom/extended color* và cho phép định nghĩa
> riêng — nên khai bằng `light-dark()` cho khớp cơ chế của Material.
> Giá trị đã chỉnh cho hoà với neutral ám teal của palette mới.

```css
@import "tailwindcss";

@theme {
  /* --- Alias sang M3 role token --- */
  --color-bg: var(--mat-sys-background);
  --color-surface: var(--mat-sys-surface-container-low);
  --color-surface-2: var(--mat-sys-surface-container);
  --color-border: var(--mat-sys-outline-variant);
  --color-border-strong: var(--mat-sys-outline);
  --color-text: var(--mat-sys-on-surface);
  --color-text-muted: var(--mat-sys-outline);
  --color-text-faint: color-mix(in srgb, var(--mat-sys-outline) 72%, transparent);
  --color-accent: var(--mat-sys-primary);
  --color-accent-contrast: var(--mat-sys-on-primary);
  --color-accent-soft: var(--mat-sys-primary-container);
  --color-danger: var(--mat-sys-error);

  /* --- Extended color: M3 không có role tương ứng --- */
  --color-status-new: light-dark(#2e6fd1, #6ea8f5);
  --color-status-tracking: light-dark(#0f7a52, #3ddba0);
  --color-status-archived: light-dark(#6b7a77, #859490);
  --color-heat-low: light-dark(#8a6516, #c99a3e);
  --color-heat-mid: light-dark(#a05518, #e08a3e);
  --color-heat-high: light-dark(#ad3a1b, #e2603f);

  /* --- Font: trỏ về đúng family đã khai trong mat.theme --- */
  /* M3 KHÔNG có token *-font-family chung; chỉ có <scale>-font.
     brand = display-*/headline-*/title-large; plain = body-*/label-*. */
  --font-display: var(--mat-sys-title-large-font);
  --font-body: var(--mat-sys-body-medium-font);
  --font-mono: 'JetBrains Mono', monospace;
}

/* Toggle thủ công thắng cài đặt hệ điều hành */
:root[data-theme="light"] { color-scheme: light; }
:root[data-theme="dark"]  { color-scheme: dark; }

body {
  background: var(--mat-sys-background);
  color: var(--mat-sys-on-surface);
  font: var(--mat-sys-body-medium);
}
```

**Mục đích:** bỏ provider của PrimeNG, đăng ký fontset icon, gắn lại

```ts
  provideZonelessChangeDetection,
  provideEnvironmentInitializer,
  inject,
```

## Batch 6 — `src/app/core/http/error-interceptor.ts` *(ghi đè)*

**Mục đích:** thay `MessageService` của PrimeNG bằng `MatSnackBar`, giữ
nguyên bảng map lỗi trong `docs/architecture.md`.

```ts
import { HttpErrorResponse, HttpInterceptorFn } from '@angular/common/http';
import { inject } from '@angular/core';
import { MatSnackBar } from '@angular/material/snack-bar';
import { catchError, throwError } from 'rxjs';

import { ProblemDetails } from './problem-details';

export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  const snackBar = inject(MatSnackBar);

  return next(req).pipe(
    catchError((error: unknown) => {
      if (error instanceof HttpErrorResponse) {
        const problem = error.error as ProblemDetails | undefined;
        if (error.status === 404 || error.status >= 500) {
          const message =
            problem?.detail ?? problem?.title ?? 'Đã có lỗi xảy ra, vui lòng thử lại.';
          snackBar.open(message, 'Đóng', {
            duration: 6000,
            horizontalPosition: 'end',
            verticalPosition: 'bottom',
            panelClass: 'app-snackbar-error',
          });
        }
        // 400 (validation) & 409 (conflict): không snackbar — component tự đọc
        // problem.errors / problem.detail để hiện lỗi inline
      }
      return throwError(() => error);
    }),
  );
};
```

> **Vì sao gộp `title` + `detail` thành 1 chuỗi:** `MatSnackBar.open()`
> chỉ nhận `message: string` (đã verify signature) — không có khái niệm
> summary/detail 2 dòng như PrimeNG Toast. Ưu tiên `detail` vì đó là câu
> mô tả cho người dùng; `title` chỉ là fallback.
>
> **Vì sao có action "Đóng":** snackbar M3 xếp hàng tuần tự chứ không
> stack. Nếu vài request cùng lỗi, người dùng phải chờ hết `duration`
> mới thấy cái tiếp theo — nút đóng cho họ bỏ qua ngay.
>
> **Vì sao `panelClass` thay vì `severity`:** M3 không có khái niệm
> severity cho snackbar. Tô đỏ bằng class + `theme-overrides` cục bộ
> (Batch 9c).

## Batch 7 — Shell: nav rail + toolbar theo M3

### 7a. `src/app/layout/shell/shell.ts` *(ghi đè)*

**Mục đích:** thêm `MatIconModule` / `MatToolbarModule` / `MatRipple` vào
imports; phần logic `pageTitle` giữ nguyên như đang chạy.

```ts
import { Component, inject } from '@angular/core';
import { toSignal } from '@angular/core/rxjs-interop';
import {
  ActivatedRoute,
  NavigationEnd,
  Router,
  RouterLink,
  RouterLinkActive,
  RouterOutlet,
} from '@angular/router';
import { MatIconModule } from '@angular/material/icon';
import { MatToolbarModule } from '@angular/material/toolbar';
import { MatRipple } from '@angular/material/core';
import { filter, map } from 'rxjs';

@Component({
  selector: 'app-shell',
  imports: [
    RouterLink,
    RouterLinkActive,
    RouterOutlet,
    MatIconModule,
    MatToolbarModule,
    MatRipple,
  ],
  templateUrl: './shell.html',
  styleUrl: './shell.css',
})
export class Shell {
  private readonly router = inject(Router);
  private readonly route = inject(ActivatedRoute);

  protected readonly pageTitle = toSignal(
    this.router.events.pipe(
      filter((event): event is NavigationEnd => event instanceof NavigationEnd),
      map(() => this.deepestTitle()),
    ),
    { initialValue: '' },
  );

  private deepestTitle(): string {
    let current = this.route;
    while (current.firstChild) {
      current = current.firstChild;
    }
    return current.snapshot.data['title'] ?? '';
  }
}
```


> **Vì sao override bằng `--mat-chip-*` chứ không class Tailwind:** style
> của Material component gắn vào class riêng (`.mat-mdc-chip`), specificity
> cao hơn utility class của Tailwind — viết `bg-...` lên `<mat-chip>` sẽ
> **không ăn**. Đây là cái bẫy chính khi trộn Tailwind với Material, và
> cách đúng là đi qua token của component. Đã ghi lại trong Batch 10.
>
> **Vì sao `color-mix` 18%:** M3 không sinh sẵn container color cho custom
> color. Trộn 18% với nền cho ra sắc độ tương đương `*-container` của M3
> ở cả sáng lẫn tối mà không phải khai 6 hex nữa.
>
> **Vì sao có `prefers-reduced-motion`:** dot pulse chạy vô hạn — spec
> a11y của M3 yêu cầu tắt animation lặp khi người dùng bật giảm chuyển
> động. Bản PrimeNG cũ chưa có.

## Batch 10 — Cái bẫy cần nhớ khi code tiếp

1. **Tailwind utility không đè được style Material.** `.mat-mdc-*` có
   specificity cao hơn. Muốn đổi màu/bo góc/kích thước của component
   Material → dùng `--mat-*` token của component đó (như Batch 8b), hoặc
   `mat.theme-overrides` cho token hệ thống. Chỉ dùng Tailwind cho
   layout quanh component (`flex`, `gap`, `p-4`) và cho markup tự viết.
2. **`!important` của Tailwind (`!bg-...`) là lối thoát hiểm**, đã dùng ở
   `mat-toolbar` Batch 7b vì toolbar chỉ cần đổi nền. Đừng biến nó thành
   thói quen.
3. **Component render trong overlay** (dialog, snackbar, menu, tooltip,
   select) nằm ngoài cây DOM component → style phải đặt global.
4. **Density đã set `-2` toàn cục.** Đừng chỉnh chiều cao row/button bằng
   tay ở từng chỗ; nếu thấy chật/rộng thì chỉnh 1 con số ở Batch 2.
